# 淫語・擬音・♡喘ぎ 語彙帳

エロ漫画／同人小説系の官能表現を「語彙の在庫」として持つためのファイル。
濡れ場を書く前に開き、**同じ語の反復を避けて回す**ために使う。
場面の温度に合わせて段（婉曲→直接→下品）を選ぶのが基本。

---

## 1. ♡喘ぎ（ハート喘ぎ）

喘ぎ声の末尾にハート記号を付す表記法。エロ漫画発祥で、近年は小説でも定番。
**理性が飛んでいる／快楽に浸っている状態の可視化**が本質で、付ければ付くほど
「余裕がない」ことを示す。冷静な台詞や地の文には付けないことで落差が生まれる。

- 記号の種類で色を変えられる：`❤️`（標準）`♡`（軽い・かわいい）`💜`（堕ち・毒気）
  `💫`（意識が飛ぶ）`💢`（強がり・悔しさ）`✌`（アヘ・白目のおどけ）
- **数で強度を示す** — 余裕あり `ん❤` → 崩れ `あ゛っ❤️❤️` → 限界 `イグぅ❤️❤️❤️💫`
- 地の文には付けない。**台詞・モノローグ限定**にすると、語り手の冷静さとの対比が効く。

### 濁点喘ぎ
本来濁点の付かない音に濁点を付け、喉が潰れた・声が歪んだ状態を表す。
`あ゛／お゛／え゛／ん゛／ひ゛` — 苦しさと快楽が混ざった生々しさが出る。
例：`お゛っ❤️`『あ゛あ゛あ゛っ❤️❤️』`ん゛ぅ゛〜〜っ❤️`

### 汚喘ぎ（きたな喘ぎ）
美しく整えず、あえて品のない・間抜けな響きにする技法。
`おほぉ／んほぉ／ぶひっ／ひぎっ／ごぼぉ` など。ギャップ芸と相性が良く、
気取っていたキャラほど効果が大きい。多用すると笑いに寄りすぎるので決め所で。

### 崩壊の段階表
| 段階 | 例 |
|------|-----|
| 余裕 | `ん……❤` `ふふ、かわいい❤` |
| 兆し | `あ……っ❤` `ちょ、待っ……❤️` |
| 崩れ | `あ゛っ❤️❤️` `やだ、そこ……っ❤️💫` |
| 限界 | `イグッ、イグイグッ❤️❤️💫` `だめだめだめぇ❤️💢` |
| 絶頂 | `お゛ほぉ〜〜んっ❤️❤️❤️💫💫` |
| 余韻/アヘ | `ほへぇ〜❤️💫✌` `にへへ……❤️💫` `とろぉ〜ん❤️` |

### 言葉が壊れる技法
- **濁点化**：`ぶっといのぉ` → `ぶっといのぉ゛`
- **拗音・小書き**：`だめ` → `らめ` `れす` `にゃっ`
- **伸ばしと途切れ**：`きもちい〜〜っ` `ま、待っ……っ`
- **反復**：`イグイグイグッ` `だめだめだめっ`
- **語の混線**：名前・単語を言い間違える／思考が飛んで別の話になる

## 2. 擬音（SFX）

**独立行に置く**とリズムが立つ。`（──ぱんっ！♡♡）` の形式。
♡の数で激しさを示し、濁点・促音・伸ばしで質感を変える。

### 粘性・愛撫
`ぬちゃ／ぬちゅ／くちゅ／にちゃ／ねちょ／とろ／ぬる／ぬぷ／くぱぁ`

### 手コキ・自慰
`しこ……しこ……`（緩）→ `しこしこしこっ`（急）→ `ぱちゅぱちゅっ`（加速）
`じゅぷっ／ぬぷぬぷ／ぐちゅぐちゅ`

### 口淫
軽い：`ちろ／ちろちろ／れろぉ／ぺろぺろ／ちゅ／ちゅぱ`
深い：`じゅぽ／じゅっぽ／じゅぶぶ／じゅぼじゅぼ／ぱくっ`
吸引：`ずぞぞぞっ／じゅるるっ／ちゅうぅ〜`
離す：`ちゅぽんっ／ぷはっ`
喉：`んぐっ／おぇっ／ごぷっ／こく、こく／ごくんっ`

### 挿入・抜去
挿入：`ずぶっ／ずぷぅ／ぬぷぷ／みちみち／ずりゅっ／ぬっぽぉ`
抜去：`ずるるっ／ぬぽんっ／ぼろんっ／ずぞぞ`

### ピストン
`ぱんっ／ぱんぱんっ／ばちゅっ／どちゅっ／どちゅうんっ／ずちゅっ／ぐちゅんっ`
奥突き：`ごつっ／ずんっ／どすっ／ぐりぐり`

### 露出・解放
`ぶるんっ／ぼろんっ／ぽろんっ／ぷりんっ／びたんっ`（腹打ち）`ぺちっ／ぺちんっ`

### 射精・潮
`びゅくっ／びゅるるっ／どぷっ／どぴゅっ／びゅくびゅく／どくどく`
潮：`ぷしゃぁっ／しゅわぁ／ぴゅーっ`
垂れ：`ぽたっ／とろぉ〜／だらぁ`

### 痙攣・絶頂
`びくんっ／びくびくっ／がくがくっ／びっくぅ〜んっ／ぴくぴく`

### 表情・空気
`ニマニマ／とろぉ〜ん／ぼーっ／こく（頷き）／ごくり（生唾）`

## 4. 役割分担：誰に何を言わせるか

淫語を全員に均等に喋らせると散らかる。**役割を割り振る**と場面が締まる。

- **攻め／年上側** — 下品な語と煽りを担当。「童貞チンポおいしい」「ぜんぶ出しなさい」。
  相手の状態を実況・言語化する役でもある（読者に状況を伝える機能を兼ねる）。
- **受け／草食側** — 謝る・否定する・懇願するのが基本。「ごめんなさい」「だめです」「待って」。
  下品な語は自分からは使わず、**言わされる**（復唱させられる）と落差が出る。
- **単体もの（ソロ）** — 一人二役。自分を煽り、自分でツッコむ。淫語も自分に向けて使う。

## 5. アンチパターン

- **同語反復** — 「気持ちいい」「熱い」を数行おきに繰り返すと一気に安くなる。
  上の表から必ず別の語に置換する。
- **擬音の均一化** — `ぱんぱん` だけで通すと単調。速度・深さ・粘度で音を変える。
- **♡の付けっぱなし** — 全部の台詞に付けると強度の差が消える。冷静な台詞は素にする。
- **汚喘ぎの多用** — `おほぉ` を連発すると笑いに寄りすぎてエロが飛ぶ。決め所に絞る。
- **説明的な淫語** — 部位の位置関係を精密に語ると図解になる。感覚に寄せる。
- **受けが饒舌** — 草食系主人公が下品な語を流暢に喋ると、受け身の魅力が消える。
