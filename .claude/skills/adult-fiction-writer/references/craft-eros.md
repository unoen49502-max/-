# 官能描写の技法

濡れ場・情事を書くときに参照する。原則は「説明しない、実況する」。以下は道具箱であって、
全部を毎回使う必要はない。場面の温度とキャラに合わせて取捨選択する。

## 1. シーンの設計：行為の前に感情がある

官能シーンは、性的行為の手順書ではない。**二人の関係がその場面でどう動くか**が背骨で、
体の描写はその感情を運ぶ乗り物。設計するとき次を先に決める。

- **入口の温度** — 気まずさ／じらし／勢い／甘え。どこから始まるか。
- **転換点** — 遠慮が消える瞬間、主導権が入れ替わる瞬間、感情が言葉になる瞬間。ここが山。
- **出口の余韻** — 事後に何が変わったか。満たされた沈黙、照れ、不安、新しい距離。

行為の最中も「気持ちいい」の一本調子にせず、感情の小さな起伏（ためらい→受容→没入→解放）を
体の反応に翻訳して並べると、単調にならない。

## 2. 五感の配分：全部盛りにしない

その瞬間に当人が**一番強く感じているひとつ**に寄せると、かえって生々しい。

- **視覚** — 相手の表情、目線、肌の色、体の線。ただし俯瞰的な描写を続けると他人事になる。
- **聴覚** — 息、声、衣擦れ、水音。声の「震え」「掠れ」「こらえ」は感情の露出として強い。
- **触覚** — 体温、汗の湿り、力の入り方、肌理。官能の中心。抽象語（気持ちいい）でなく、
  「どこに」「どんな」感覚が「どう」広がったかを具体で。
- **視点保持者の内側** — 心拍、呼吸の乱れ、思考が飛ぶ感覚、羞恥と欲の綱引き。

相手の内心は直接書かない（三人称の視点固定）。相手が何を感じているかは、
**観測できる兆候**（息を呑む、力が抜ける、名前を呼ぶ）で読者に推測させる。そのほうが色っぽい。

## 3. 緩急とテンポ：文でリズムを作る

- **高まり** — 短い文、体言止め、畳みかけ。主語や接続を省いて速度を上げる。
- **余韻・静** — 長い一文でゆっくり流す。時間が伸びた感覚を文の長さで再現する。
- **間（ま）** — 行為の合間の沈黙、視線が合う一拍、名前を呼ぶ前のためらい。
  この「何もしない瞬間」が、次の動きを効かせる。
- **じらし** — 読者にも登場人物にも「まだ」を作る。すぐ与えると解放のカタルシスが痩せる。

## 4. 語彙：反復を殺し、温度で使い分ける

同じ語が数行おきに出ると一気に安っぽくなる。言い換えの引き出しを持って回す。
また、直接的な語と婉曲な比喩は**場面の温度**で使い分ける。前戯や甘い場面は比喩寄り、
最高潮は直接的に、と振ると緩急がつく。

- 「熱い／火照る／燃える／茹だる／滾る」のように**同義の束**で回す。
- 「気持ちいい」は要約語。使うなら一度きりの決め台詞に取っておき、普段は感覚の具体で描く。
- 比喩は使い古し（「電流が走る」「頭が真っ白」）を避け、そのキャラ・その世界の語彙で作る。
- オノマトペは効くが乱発すると軽くなる。ここぞで一つ。

## 5. 会話と喘ぎ：人格を崩さない

- 行為中の台詞も**そのキャラの口調**を保つ。普段クールなキャラが急に甘い言葉を連発すると、
  演出意図が無ければ違和感になる。ギャップを狙うなら、その落差自体を丁寧に描く。
- 喘ぎ・吐息は文字化しすぎると滑稽になる。数を絞り、途切れた台詞（「……っ、まって、」）や
  地の文の描写と混ぜて、生々しさと品を両立させる。
- 相手を呼ぶ「呼称」の変化（他人行儀→名前→呼び捨て→愛称）は関係の進展を無言で示せる強い手。

## 6. 避けたい型（アンチパターン）

- **手順書化** — 「次に〜した。それから〜した」の動作列挙。感情と感覚が抜けると、
  行為の実況が取扱説明書になる。
- **視点のブレ** — 三人称で相手の内心を勝手に断定する。観測できる兆候で示す原則に戻る。
- **要約への逃げ** — 「二人は結ばれた」「至福の時間だった」で肝心の場面を飛ばす。
  読者が読みたいのはその中身。
- **語彙の一本調子** — 同じ形容・同じ動詞の反復。3〜4節ですでに単調になる。
- **人格の消失** — 行為に入った途端キャラが記号になる。声を保ち続ける。
- **説明過多の解剖** — 位置関係を過度に精密に書くと、色気より図解になる。要点を絞る。

## 7. 事後（アフター）を書く

余韻は作品の格を上げる。行為が終わった後の、呼吸が整うまでの沈黙、交わす短い言葉、
触れ方の変化、どちらかの不意の弱さ——ここで**関係が一段進んだこと**を見せると、
単発のシーンが物語になる。連載なら、この余韻が次話の温度と引きに直結する。

## 8. register の振れ幅：しっとり ↔ ド下品ハイテンション

同じ「官能」でも、狙う温度で文体を大きく振る。上の 1〜7 は**しっとり寄り**（余韻・比喩・
静けさ）の基本。一方で、笑いと勢いで押し切る**ド下品・ハイテンション様式**もあり、
pixiv 等ではこちらの需要が非常に大きい。どちらもツールとして持ち、作品ごとに選ぶ。

**このユーザーの既定は「ド下品・ハイテンション」寄り。**指定がなければこちらを基調にする。
ただし「しっとり」と明示されたら 1〜7 の静かな作りに切り替える。

### ド下品・ハイテンション様式の道具

- **記号で感情の振れ幅を可視化** — `❤️💜♡💢💫✌` を喘ぎ・興奮・照れ・イキ堕ちに合わせて連打。
  多いほど「余裕がない／快楽に飲まれている」を表す。冷静な地の文には付けない。
- **擬音を独立行で置く** — `（──ぱんっ！♡♡　どちゅうんっ！！♡♡♡）` のように行を割って挿入。
  視覚的なリズムとテンポを作り、速度をSFXの密度で示す（`しこ…しこ…`＝緩、`しこしこしこっ！`＝急）。
- **崩れ喘ぎ** — `お゛っ／おほぉ〜ん／イッグゥ／ほへぇ〜ん／ひゃぅっ` など、正しい発音を崩して
  理性の欠落を表現。濁点・小書き・伸ばしで歪ませる。数を絞らず畳みかけてよいのがこの様式。
- **ツッコミ／ボケのモノローグ** — 「男ってずっとこの解像度で生きてんの!?」のように、
  快楽に溺れながら早口でツッコむ。下品さと笑いを両立させる、この様式の背骨。
- **イキがり→完堕ちの反転（メス堕ちギャップ）** — 強気・余裕の仮面が、絶頂で一気に剥がれて
  `白目ダブルピース`のような間抜け顔に落ちる落差が笑いと快楽の核。強気の台詞を先に積むほど効く。
- **オチで締める** — 事後を「賢者タイム来ない／まだ勃ってる／次はもっと」と勢いで引く。
  しっとりの「余韻」ではなく、テンションを落とさず次へ繋ぐのがこちらの流儀。

しっとりの技法（五感の実況・視点固定・キャラの声維持）はこの様式でも生きる。
崩すのは「静けさ」と「品」であって、感覚描写の解像度は落とさない。

## 9. 単体もの（ソロ）と長回しの段階設計

一人でのオナニー描写など相手のいない単体ものは、**本人視点の内面実況**が最強。
「何を見て・どこがどう気持ちいいか・体がどう反応したか」を一人称で畳みかける。
鏡・自撮り・妄想など「自己完結する仕掛け」を軸にすると、相手がいなくても話が回る。

長く気持ちよさを見せたいときは、一回の行為を**段階で刻んで滞在時間を伸ばす**：

1. **導入** — 触れただけ／握っただけの初期反応。まだ余裕がある。
2. **緩** — ゆっくり動かし、弱点（敏感な箇所）を探り当てて実況する。
3. **焦らし（寸止め）** — イキそうで手を止める。「もったいない」と自分を焦らす。溜めを作る。
4. **急** — 一気に加速。擬音を密に、喘ぎを崩し、思考が飛ぶ。
5. **絶頂** — 独立行のSFXで解放。記号マシマシ。
6. **余韻＆引き** — 「まだ勃ってる」「次はもっと」で、テンションを落とさず次へ。

焦らし（3）を複数回はさむと、快感のアピールをいくらでも引き伸ばせる。時間跳躍（`×　×　×`）を
多用すると「1日中」の量感は出るが、快感の濃度は薄まる。**濃く見せたい回は跳躍を減らし、
ワンセッションに滞在する。**
