# なろう系・pixiv 連載の作法

Web 連載として投稿する体裁・構成・運用のまとめ。本文の質とは別に、
「読まれ続ける」ための工学的な部分を扱う。

## 1話の構造：掴み → 展開 → 引き

Web 連載は**1話ごとに読者が離脱を判断する**。だから各話が小さな起承転結を持つ。

- **掴み（冒頭）** — 頭の数行で前回の温度を取り戻し、この話の「今日の見どころ」を予感させる。
  長い状況説明・世界観の再解説で始めない。会話や動きから入るとページが動く。
- **展開（中盤）** — このシーンのゴール（関係の変化）に向けて緊張を積む。
- **引き（末尾）** — 次を読みたくさせて切る。特に**本番・急展開の直前**で切ると継続率が上がる。
  ただし毎回同じ場所で焦らすと飽きられるので、たまに満足させる回も混ぜて緩急をつける。

## 1話の長さ

- 目安 **2,000〜5,000 字**。スマホで一気に読める分量。長すぎると離脱、短すぎると物足りない。
- 官能回は少し長めでも読まれる。逆に日常・溜め回は短めでテンポよく。
- 1話 = 1シーン（1場面）を基本に。場面転換を1話に詰め込みすぎない。

## 冒頭・あらすじ・タグ（求められたら用意する）

- **あらすじ** — 検索結果と作品トップで最初に読まれる。世界観+関係+フック（何が読めるか）を
  数行で。ネタバレしすぎず、続きを読ませる引きで締める。
- **タグ／キーワード** — 内容に即した属性を並べる。読者は属性でたどり着く。過不足なく。
- **注意書き（地雷回避）** — 含まれる要素・属性を冒頭やあらすじで明示するのは、読者への誠実さ。
  「これが読める作品」を正しく届けることで、合う読者に届き、合わない読者を守る。

## 投稿記法

サイトによって記法が異なる。求められた媒体に合わせる。

- **ルビ（なろう記法）** — `｜漢字《かんじ》`。傍点は `《《強調》》`（サイト依存）。
- **pixiv** — ルビは `[[rb:漢字 > かんじ]]`。チャプター機能で話を分ける。
- 記号・ルビの乱用は読みにくい。ここぞの一語に絞る。
- 三点リーダは `……`（偶数個）で。ダッシュは `——`。半角の乱れに注意。

## 継続率を上げる運用の勘所

- **更新のリズム** — 引きで切った翌話は、焦らしすぎず早めに解放して信頼を作る。
- **溜めと放出の設計** — 緊張（すれ違い・お預け）を溜めた分だけ、放出（結ばれる回）が効く。
  連載全体でこの呼吸を設計する。溜めっぱなしは離脱、放出ばかりは飽き。
- **感想への意識** — 山場の回、引きの回は反応が集まりやすい。そこに向けて筆を乗せる。

## 連載の一貫性チェック

各話を書く前後で、設定資産（`characters/`・`glossary.md`・`outline/`）と照合する。

- キャラの一人称・呼称・口調が既出とずれていないか。
- 関係の進展段階（呼称・距離）が前話と連続しているか。巻き戻っていないか。
- 固有名詞の表記ゆれがないか。
- 前話の引きを、今話の冒頭が正しく受けているか。
