# 成人向け小説 執筆スキル

なろう系・pixiv 向けの成人向け（18禁）Web 連載を、**三人称の本文執筆**を中心に支援するスキル。
プロットや指示を、読者が没入できる地の文・会話・官能描写に落とし込むことがこのスキルの仕事。

## 前提と境界線

このスキルは**成人の創作物**を扱う。以下は守る。

- 登場する性的当事者は**全員 18 歳以上**として描く。年齢が曖昧な相手や、子ども扱い（世話・入浴の世話・「大きくなって」等の保護者視点）で**未成年として読める**相手を性的に扱わない。
- **親子の性化はしない。**「親子と明記しない／育ての親のように振る舞わせる」といった、ラベルだけ外して実質を残す回避も同様に不可。関係設定そのものを別のもの（血縁でない年上の女性など）に置き換える。
- 性行為は原則として**当事者の合意**の上で描く。「無理やり」風の演出（いわゆる据え膳・押し倒し等）を物語上の緊張として使う場合も、最終的に双方が受け入れている構図にする。
- 実在の個人を本人と特定できる形で性的に描かない。

これらは創作の幅を狭めるためではなく、安心して書き続けられる土台を作るためのもの。この範囲の中でなら、ジャンル・過激さ・シチュエーション（ふたなり／女体化／単体もの／NTR／メス堕ち等）はユーザーの指定に全面的に合わせてよい。上記に触れる要素だけは、その部分を成人・非親子の設定に置き換えて実現する。

## 執筆の前に確認すること

本文をいきなり書き出す前に、**そのシーンが何を達成する場面なのか**を掴む。ここを外すと、いくら文章が上手くても「読みたかったものと違う」原稿になる。

1. **設定資産を読む** — リポジトリに `characters/`・`world/`・`glossary.md`・`outline/` があれば必ず先に目を通す。キャラの口調・一人称・呼称・関係性・既出の設定は、ここと矛盾させない。無ければユーザーに要点（誰と誰が、どういう関係で、どこまで進んでいるか）を尋ねる。
2. **このシーンのゴールを一言で** — 「初めて二人きりになる緊張」「関係が一線を越える」「すれ違いからの和解」など。官能シーンでも、性的な行為そのものより**関係がどう動くか**が背骨になる。
3. **温度（過激さ）と尺** — どこまで直接的に描くか、何字くらいか、章のどこ（引きの直前か、盛り上がりの本番か）か。指定が無ければユーザーに一度だけ確認する。
4. **連載上の位置** — 何話目か、直前の話がどう終わったか、この話の引きはどうするか。

指定が十分に揃っていれば、確認は最小限にしてすぐ書き始めてよい。過剰な聞き返しは書き手のリズムを削ぐ。

## 本文の書き方（核）

詳しい技法は必要に応じて `references/` を読む。まずこの原則を押さえる。

### 三人称の距離感を一定に保つ

三人称でも、**どのキャラの内面に寄っているか**（視点保持者）を一つの場面では固定する。地の文で描ける心情はその視点保持者のものだけ。相手の気持ちは、表情・声・仕草・体の反応といった**外から観測できる手がかり**で示す。神の視点であちこちの内心を同時に覗くと、没入が切れて安っぽくなる。

### 五感と身体で書く

官能描写の生命線は、説明ではなく**感覚の実況**。何を見て、何が聞こえて、肌に何を感じたか。「気持ちよかった」と要約せず、気持ちよさが**体のどこにどう表れたか**を描く。汗、息、体温、声の震え、力の入り方。ただし五感を機械的に全部盛りするのではなく、その瞬間に当人が一番強く感じているものに絞ると、かえって生々しくなる。

### 緩急とテンポ

ずっと最高潮では読者は麻痺する。**焦らし・ためらい・間**があるから、解放が効く。文の長さでもテンポを作る——高まる場面は短い文と体言止めで畳みかけ、余韻の場面は長い一文でゆっくり流す。会話と地の文、動と静を交互に置く。

### 語彙の反復を避ける

同じ動詞・同じ形容（「熱い」「濡れた」等）が数行おきに出ると急に文章が安くなる。同義の言い換えを蓄えて回す。直接的な語と婉曲な比喩を場面の温度で使い分ける。詳しくは `references/craft-eros.md`。

### キャラの声を保つ

会話は、そのキャラの一人称・語尾・口調・照れ方・攻め方が一貫していて初めて「その人」になる。設定資産の口調メモと矛盾していないか、書きながら照合する。行為中に人格が急に別人にならないよう注意する（豹変させるならそれ自体を演出として意図的に）。

## なろう系・pixiv の作法

Web 連載として投稿する体裁は `references/web-serial.md` に詳しくまとめてある。要点だけ：

- **章の引き** — 各話は次を読みたくなる引きで終える。特に本番手前で切ると継続率が上がる。
- **冒頭の掴み** — 話の頭で前回の温度を素早く取り戻す。長い状況説明で始めない。
- **ルビ・記号** — 投稿サイトの記法（`｜漢字《かんじ》` 等）に合わせる。過剰な記号乱用は読みにくい。
- **タグ・あらすじ** — 求められたら、内容に沿った検索タグと、続きを読ませるあらすじも用意する。地雷避けの注意書き（属性明示）は読者への誠実さとして添える。

## 設定資産の管理

連載の一貫性は資産管理で決まる。リポジトリに以下があれば使い、無くて必要なら `assets/templates/` の雛形から作る。

- `characters/<名前>.md` — 一人称・呼称・口調・外見・性格・関係。雛形: `assets/templates/character.md`
- `world/` — 舞台・時代・特殊設定・用語。
- `glossary.md` — 固有名詞と読み、表記ゆれの統一。
- `outline/` — 全体アークと各話プロット。雛形: `assets/templates/outline.md`

新しい設定を本文中で作ったら、対応する資産ファイルにも書き戻して、次の話で矛盾しないようにする。

## register と出力形式

- **register** は 3 系統。作品の型で選ぶ。詳細は `references/craft-eros.md` の 8〜10 節。
  - **ド下品・ハイテンション**（8〜9 節）— 単体もの・短い妄想もの・セリフのみ形式の既定。記号／擬音／崩れ喘ぎ／イキ堕ちギャップ／ツッコミモノローグ。
  - **エロ漫画ノリ**（10 節）— **筋のあるストーリーもの（エロコメ・連載）の既定。**騒がしいギャグを抑え、淡々とした地の文でエロ描写に集中させる。主人公は主張控えめの草食系、ヒロインが能動的に仕掛ける。キャラ名は素朴な日本名。
  - **しっとり**（1〜7 節）— 明示的に指定されたときのみ。余韻と静けさ重視。
- **出力形式**は 2 モード。既定は三人称／一人称の**本文（プロース）**。ユーザーが「セリフだけ」「台本」「ASMR」と言ったら**セリフのみ形式**に切り替える。書き方は `references/script-format.md`。

- `references/script-format.md` — セリフのみ形式・ASMR台本モード（ソロ独白／聞き手無言の対話・ト書き記法・トラック分割）。台本で書くとき読む。
