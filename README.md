# Dot Slash FX — ドットエフェクト制作ツール

高精度なドットエフェクト／ドットグラフィックを制作するための自作エンジンと、
その第一弾として作成した**斬撃エフェクトアニメーション5種**です。

すべてコードから決定論的に生成されます（外部素材なし）。フレーム／透過スプライトシート／
GIF／目視確認用コンタクトシートを一括出力します。

## 斬撃エフェクト一覧

| # | 名称 | 動き | 色 |
|---|------|------|----|
| 01 | 横薙ぎ (Horizontal) | 上方を左→右に薙ぐ三日月斬 | シアン |
| 02 | 袈裟斬り (Diagonal) | 右上→左下へ抜ける長刀の一閃 | クリムゾン |
| 03 | 十字斬り (Cross) | 二連斬が交差し閃光が炸裂 | ゴールド |
| 04 | 回転斬り (Spin) | 一回転して衝撃波リングへ拡散 | エメラルド |
| 05 | 斬り上げ (Rising) | 左下→右上へ立ち上がる斬撃 | バイオレット |

全体像は `out/OVERVIEW.png`、アニメは `out/gallery.html` で確認できます。

## 使い方

```bash
npm install
npm run build          # 全エフェクト + 一覧 + HTMLギャラリーを生成
npm run effects 03     # 名前に "03" を含むエフェクトだけ再生成
```

出力は `out/<name>/` に：

- `frame_NN.png` … ダーク背景プレビュー（ゲーム内の見え方）
- `alpha_NN.png` … 透過スプライト（任意の背景に合成可能）
- `<name>_spritesheet.png` … 横並び透過スプライトシート
- `<name>_contact.png` … 全フレーム一覧（目視QA用）
- `<name>.gif` … ループアニメーション

## エンジン構成 (`src/`)

| ファイル | 役割 |
|----------|------|
| `canvas.js` | 浮動小数の光量蓄積バッファ（加算合成HDR）。トーンマップ後に**パレット量子化**して、白熱コア→有色エッジのクリスプなドット階調で書き出す。色相非依存に最大チャンネル値でバンド選択。 |
| `draw.js` | 描画プリミティブ。`slashBand`（極座標で三日月刃をラスタライズ／全周アーク対応）、`beam`（直線ビーム）、イージング、シード付き乱数。 |
| `palette.js` | 斬撃ランプ生成と名前付きパレット（cyan/crimson/emerald/violet/gold）。 |
| `slashAnim.js` | 斬撃ライフサイクル（予備動作→高速スイープ→散り際＋火花）を再利用可能に。`arcFromChord`（2端点＋反りからアーク算出）、`paintBlade`、`sparkBurst`、`arcSlash`。 |
| `effects/*.js` | 各斬撃の定義。多くは `arcSlash` への薄い設定ラッパ。 |
| `render.js` | フレーム／シート／GIF出力。 |
| `overview.js` / `gallery.js` | 一覧PNG／HTMLギャラリー生成。 |

## 品質設計メモ

- **ドット感**: 連続グラデーションではなく明度バンドへ量子化し、最近傍拡大で
  クリスプなピクセルにする。白熱コアと有色エッジが階調として分離して見える。
- **斬撃の説得力**: 先頭（リーディングエッジ）が最も明るく太く、尾に向かって細く暗く。
  スイープは ease-out で「速く入って止まる」。散り際に細く＋接線方向へ火花。
- **新エフェクトの追加**: `src/effects/` に定義を1ファイル足すだけ。アーク斬撃なら
  `p1`/`p2`/`bow`（2端点＋反り）で直感的にジオメトリ指定できる。
