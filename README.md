# デスクトップマスコット

デスクトップの上をネコのキャラクターが歩き回る PC アプリです。
Electron 製で、Windows / macOS / Linux で動作します。

![キャラクター](https://img.shields.io/badge/%F0%9F%90%B1-desktop%20mascot-f5a34a)

## できること

- 画面の下(タスクバーの上)を勝手に **おさんぽ・ダッシュ・立ち止まり・おすわり・居眠り** します
- **マウスでつかんで持ち上げ**られます。放すと重力で落ちて、勢いをつけて **投げる** こともできます
- **クリックするとなでられて喜び**、たまに吹き出しでおしゃべりします
- キャラクター以外の場所は **クリックが素通し** されるので、作業のじゃまになりません
- **右クリック** またはタスクトレイのメニューから操作できます

| 操作 | 動作 |
| --- | --- |
| 左クリック | なでる(喜ぶ) |
| ドラッグ | つかんで持ち運ぶ / 投げる |
| 右クリック | メニュー(まんなかに呼ぶ / おさんぽ停止 / 終了) |
| トレイアイコン | 同上のメニュー |

## 動かし方

Node.js(18 以上推奨)が必要です。

```bash
npm install
npm start
```

## 配布用にビルドする

```bash
npm run dist
```

`dist/` 以下に、Windows ならポータブル exe、macOS なら dmg、Linux なら AppImage が生成されます。

## しくみ

- 透明・枠なし・最前面のウィンドウを作業領域いっぱいに広げ、その中で DOM のキャラクターを動かしています(`main.js`)
- `setIgnoreMouseEvents(true, { forward: true })` でウィンドウ全体をクリック透過にしつつ、キャラクターにマウスが乗った瞬間だけ IPC で操作可能に切り替えています(`renderer.js` / `preload.js`)
- キャラクターの見た目は画像を使わず CSS だけで描いています(`style.css`)。色や形を変えたいときはここをいじってください
- 歩く・眠るなどの行動は `renderer.js` の `pickNextAction()` が一定時間ごとに抽選しています。セリフも同ファイルの `CHATTER` 配列で追加・変更できます

## 制限・メモ

- キャラクターはプライマリディスプレイの作業領域内を動きます
- Linux ではウィンドウの透過にコンポジタ(GNOME / KDE 等では標準で有効)が必要です
- クリック透過中のマウス位置検出(`setIgnoreMouseEvents` の `forward` オプション)は Windows / macOS 向けの機能です。Linux ではキャラクターをつかむ操作が効かない場合があります
