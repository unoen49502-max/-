# クリスタル・オブ・エルドラ — DEMO

SNES風・見下ろし型アクションアドベンチャーの**完全オリジナル**デモゲームです。
ストーリー・キャラクター・ドット絵グラフィック・BGMはすべて本リポジトリ内で自作したものです
(既存作品の素材・キャラクター・楽曲は一切使用していません)。

![ジャンル](https://img.shields.io/badge/genre-action--adventure-blue)
![形式](https://img.shields.io/badge/tech-HTML5%20Canvas%20%2B%20WebAudio-green)

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要・依存なし)。

```bash
# ローカルで開く
open index.html          # macOS
# または任意の簡易サーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

### 操作方法

| キー | 操作 |
|------|------|
| 矢印キー / WASD | 移動 |
| Z / スペース | 剣で斬る(草むらも切れます) |
| X | 話す・調べる |
| Enter | 決定・スタート |
| M | サウンド ON/OFF |

スマホ・タブレットでは画面下部にタッチ操作ボタンが表示されます。

## デモ版の内容

- オーバーワールド6画面(村・草原・森・神殿・岩山・洞窟入口)+ 洞窟ダンジョン3部屋
- 画面端をまたぐスクロール切り替え演出付きのシームレスなマップ移動
- 剣アクション・敵3種(スライム・コウモリ・骸骨)+ ボス戦「ヴォルグの影」
- ハート制HP・宝石集め・小さな鍵と鍵扉・宝箱・**ハートの器**(最大HP増加の隠し宝)
- 茂み/背の高い草を剣で切ると宝石やハートが出ることがある
- NPCイベント(村長ドムス・賢者ミラ・**傷を癒す森の精**)、各地の**看板**
- キャラや敵にドロップシャドウ、ダンジョンには揺らめく松明の灯り
- タイトル画面・オープニングストーリー・エンディングまで一通りプレイ可能
- WebAudioによる自作チップチューンBGM(フィールド曲・ダンジョン曲・ボス曲)と効果音

所要時間:約5〜10分

## 技術メモ

- 単一の `index.html` で完結(外部アセット・ライブラリなし)
- 論理解像度 256×224 のオフスクリーンバッファに描画し3倍拡大(`image-rendering: pixelated`)
- スプライトは文字列で定義したピクセルデータから Canvas に生成
- タイルはコードで手続き的に描画(水面アニメーション等)
- BGM・効果音は WebAudio のオシレーターでリアルタイム生成
