# クリスタル・オブ・エルドラ — 設定資料(デモ版)

*SNES風・見下ろし型アクションアドベンチャー(完全オリジナル作品)*

---

## 世界観

かつてエルドラ王国は、天空より落ちた聖なる宝玉 **「光晶(こうしょう)」** の加護に包まれていた。
光晶は大地に実りを、民に安らぎを与え、闇の住人たちは森の奥深くへと退いていた。

しかし月の欠けた夜――
影の魔導士 **ヴォルグ** が神殿を襲い、光晶を三つに砕いた。
欠片は各地へ飛び散り、加護を失った大地には魔物が溢れ始める。

草原の村オルムに住む若き剣士 **アレン** は、
賢者 **ミラ** の導きにより、光晶の欠片を求めて旅立つ。

> 「光を取り戻せるのは、剣ではなく、それを握る心。……行きなさい、アレン。」 — 賢者ミラ

## 登場人物

| 名前 | 役割 | 説明 |
|------|------|------|
| **アレン** | 主人公 | オルム村の若き剣士。青い装束と赤いマフラーは亡き父の形見。 |
| **ミラ** | 賢者 | 神殿の守り手。光晶の在り処を視る力を持つ。 |
| **村長ドムス** | 村の長 | オルム村の長老。旅の心得を授けてくれる。 |
| **ヴォルグ** | 宿敵 | 影の魔導士。光晶の力を闇に染めようと企む。デモ版では「ヴォルグの影」として洞窟最深部に現れる。 |

## 魔物図鑑(デモ版)

| 名前 | 生息地 | 特徴 |
|------|--------|------|
| ぷるる | 草原 | 緑のスライム。ゆっくり這い回る。 |
| よるばね | 森・洞窟 | 紫のコウモリ。不規則に飛び回る。 |
| ほねつき | 洞窟 | 骸骨の剣士。アレンを見つけると追いかけてくる。 |
| **ヴォルグの影** | 洞窟最深部 | ボス。闇の弾を放ち、瞬間移動する。 |

---

## デモ版の流れ

1. **オルム村** — 村長と賢者ミラに話を聞く(Xキーで会話)
2. **草原・森** — 魔物を倒しつつ東の洞窟を目指す
3. **ひかりの洞窟** — 小さな鍵を見つけ、扉を開けて最深部へ
4. **ボス戦** — ヴォルグの影を討ち、光晶の欠片(ひとつめ)を取り戻す
5. **エンディング** — 「旅は始まったばかり……」

## 操作方法

| キー | 操作 |
|------|------|
| 矢印キー / WASD | 移動 |
| Z / スペース | 剣で斬る |
| X | 話す・調べる |
| Enter | 決定・スタート |
